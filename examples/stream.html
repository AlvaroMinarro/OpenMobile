RTCPeerConnection against the emulator's RtcService; the daemon only relays JSEP signaling.

Tap/click the video to inject a tap through the control socket — coordinates are device physical pixels (scaled from the video intrinsic size). Query params: ?url= overrides the signaling WS URL (default ws://127.0.0.1:8765/v1/stream/video). VP8 is mandatory and universal in WebRTC browsers — no codec gate, any WebRTC-capable browser works. The bridge must run with streaming enabled and an RTC-capable emulator (≥36.5.11 launched with the allowlist); browsers cannot attach the X-OpenMobile-Secret header, so the bridge runs without auth for this demo.
